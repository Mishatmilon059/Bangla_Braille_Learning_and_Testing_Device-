Bangladesh Bangla Braille — 39 Bengali consonants

This package contains exactly 39 PNG files, one for each letter/sign in the
commonly taught 39-consonant Bengali alphabet. The last three (ং, ঃ, ঁ) are
classified as special/modifier characters in Braille references but are
traditionally counted in the 39-letter Bengali consonant set.

The conjuncts ক্ষ and জ্ঞ are not part of this 39-item package.
